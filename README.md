# SVODI

Программа для отдела закупок: собирает спецификации из Excel в одну сводную ведомость закупки.

Одинаковые позиции из разных файлов и листов объединяются сами, количества складываются, цены вводятся один раз.
Похожие позиции, которые программа не решилась объединить, показываются на проверку — решает человек.
Готовая сводная выгружается в Excel с формулами.

**[⬇ Скачать SVODI для Windows](https://github.com/belart16/svodi/releases/latest/download/SVODI-Setup.exe)**

## Установка

1. Скачайте `SVODI-Setup.exe` по ссылке выше.
2. Запустите его двойным щелчком и нажмите «Далее». Права администратора не нужны.
3. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите «Подробнее», затем «Выполнить в любом случае».
4. Ярлык SVODI появится на рабочем столе.

Нужна Windows 10 или 11 (64-разрядная) и браузер Microsoft Edge или Google Chrome — программа открывается в его окне.

## Что умеет

- Читает спецификации Excel (.xlsx и .xls), в том числе заявки с шапкой над таблицей и листы без строки заголовков.
- Объединяет одинаковые позиции по коду продукции или по наименованию и типу; понимает разное написание
  (латиница вместо кириллицы, тире, кавычки, «шт» и «шт.»), пересчитывает км в м.
- Показывает строки с ошибками — без количества, единицы или наименования — и даёт исправить их на месте.
- Принимает новые версии файлов: показывает, что изменилось, и сохраняет введённые цены.
- Ведёт историю всех изменений.
- Подсказки ИИ при разборе похожих позиций и чат-помощник — по желанию, со своим ключом выбранного сервиса.

## Ваши данные

Проекты хранятся только на вашем компьютере, в папке `%LOCALAPPDATA%\SVODI`. Исходные файлы Excel программа не меняет.
В интернет программа обращается только за обновлениями и — если вы сами подключили ИИ — к выбранному сервису ИИ,
когда вы задаёте ему вопрос.

## Обновления

Программа сама сообщает о новой версии: «Вышла новая версия · Обновить». Обновление ставится в один щелчок,
проекты сохраняются (перед обновлением делается их копия). Проверить вручную — внизу меню, «Проверить обновления».

Каждое обновление подписано ключом разработчика, и программа ставит его, только если подпись сходится.

## Удаление

«Параметры» → «Приложения» → SVODI → «Удалить». Проекты в `%LOCALAPPDATA%\SVODI` остаются — удалите эту папку,
если они больше не нужны.
